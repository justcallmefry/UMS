# How to tag a part so it shows in "Find Parts For Your Machine"

When you add or edit a product in Lightspeed, fill in **two attributes**. The finder
reads these to decide which machines a part fits. If you skip them, the part will not
appear in any vehicle search.

---

## 1. Riding Style  (the machine *type*)

Pick from this exact list (spelling matters):

`Dirtbike` · `ATV` · `UTV` · `Street` · `ADV/Dualsport` · `Cruiser`

- A part for one type → just that word, e.g. `Dirtbike`.
- A part that fits several types (e.g. apparel, oil) → separate with a slash:
  `Dirtbike/ATV/UTV`.

This alone gets a part into the "Also fits [type]" results. For vehicle-specific
parts, also fill in **Vehicle** below.

---

## 2. Vehicle  (the specific machines it fits)

Format: **`Make Model (year-year)`**

**Good examples** (copy this style):

| Situation | Tag it as |
|-----------|-----------|
| One machine, year range | `Yamaha YZ250F (14-26)` |
| Open-ended (still made) | `Polaris RZR XP 1000 (2020-Up)` |
| Fits two models | `Honda CRF250R/450R (02-25)` |
| Two separate machines | `Honda TRX450R (06-14) / Yamaha YFZ450R (04-13)` |
| All years of a model | `Yamaha YFZ450R` (omit the years) |
| Truly universal | `Universal Fitment` |

**Rules of thumb**

- **Use the real brand name:** Yamaha, Honda, Kawasaki, Suzuki, KTM, Polaris, Can-Am,
  Husqvarna, GasGas, Beta, Sherco, CFMoto, Arctic Cat, Triumph, BMW, Harley Davidson.
- **Name the actual model** (`YZ250F`, `SX65`, `RZR XP 1000`) — not a category.
- **Years** can be 2-digit (`14-26`) or 4-digit (`2014-2026`); use `-Up` for current.
- **Separate multiple machines with " / "** (a slash with spaces).

---

## 3. Be consistent — one spelling per machine

The finder treats `SX65` and `65SX` as **two different machines**. If half the parts
are tagged one way and half the other, a customer only sees half. **Pick one spelling
per model and stick to it.** When in doubt, match how an existing, correctly-tagged
part for that same machine is written.

---

## 4. Avoid vague tags

Tags like **"Most Years and Models"** or **"KTM/Husqvarna/GasGas Models"** tell the
finder only the *brand*. Those parts get pushed into the lower "Fits many [make] models"
section instead of the confident "X parts fit" list. Use a specific model + year
whenever you know it.

---

## Quick checklist when adding a part

- [ ] **Riding Style** set (from the list above)?
- [ ] **Vehicle** set with **Make + Model + Year** (for vehicle-specific parts)?
- [ ] Model spelled the **same way** as other parts for that machine?
- [ ] Multiple machines separated by **" / "**?

After products are updated and synced to eCom, the site team regenerates the finder
data (one command) and the new parts appear within a minute.
